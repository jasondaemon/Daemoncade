# Low Poly-F1 asset

- Title: **Low Poly-F1**
- Creator: [salasilma13](https://sketchfab.com/salasilma13)

The supplied GLB is used for the Apex Run Formula-style body and wheel geometry.
Apex Run removes the source's static wheel instances, repivots copies for runtime
steering/suspension/roll animation, scales the model to the existing vehicle
wheelbase and track, and replaces its materials with an original cyan, gold,
white, and carbon livery. No real-world team logos or textures are included.
