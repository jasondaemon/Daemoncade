# Kenney Car Kit 3.1

Author: Kenney — https://kenney.nl/assets/car-kit

License: CC0 (original License.txt included). Original selected GLBs and the
palette texture are retained for reproducibility. No trademarked vehicle
identities are claimed.

Runtime JSON meshes are generated by `scripts/build-racecar-kenney.py`.
The conversion applies node transforms, separates animated wheels, grounds
each model, and bakes the palette texture to material colors. Original front
axis is rotated to the game's negative-Z convention.
