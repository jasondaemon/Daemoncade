# Quaternius Cars Pack

Creator: Quaternius. Pack page: https://quaternius.com/packs/cars.html
Source folder linked by creator: https://drive.google.com/drive/folders/1fKlbDry77iY8KlEoxzUxIAZQL_XhzWlA
Retrieved 2026-09-16. The original License.txt distributed inside this folder
explicitly states CC0 1.0; retained verbatim. The pack-specific page also states
CC0. Do not infer this license for newer or different Quaternius packs.

OBJ and MTL originals are preserved. Run `node scripts/build-racecar-models.mjs`
from the repository root to regenerate JSON meshes: triangulated, rounded to
four decimal places, normalized to 4.3 world units long, forward -Z, ground Y=0.
Rear wheel pairs are separated by side; each wheel rotates about its own center.
No source artwork was AI-generated or replaced. Fictional garage names are game
labels, not manufacturer affiliations. Taxi and police are service variants,
not claimed as distinct production-car platforms.
